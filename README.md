# Ninja Frames
 A simple app for creating stop motion GIF animations using your computer's webcam.

 Planned features:

 - [ ] Preview Frames on Click
 - [ ] Rearranging Frames
 - [ ] Onion Skinning
 - [ ] Camera Selection
 - [ ] Camera Mirroring
 - [ ] Export Individual Frames as ZIP
 - [ ] Export to MP4
